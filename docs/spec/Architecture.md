# 국제화 / 기술 스택 / 비기능 요구사항

## 1. 국제화 (i18n)

- 한국어/영어 지원, 런타임 토글, 선택값 로컬 저장.
- 국가명·UI 문자열 모두 다국어 리소스로 관리. (라이브러리: `react-i18next` 등)

## 2. 기술 스택 / 아키텍처

- **React + Vite + TypeScript**, 모바일 우선 반응형(필요 시 PWA로 확장).
- 폴더: `domain`(순위·시뮬 계산, 순수 함수·테스트 집중), `data`(API 어댑터),
  `state`(전역 상태), `features`(화면), `i18n`, `components`.
- 순위·시뮬레이터 계산은 **순수 함수**로 분리해 단위 테스트 우선 작성(글로벌 워크플로우 규칙).
- 파일 PascalCase, `index.*` 금지, 문자열 유니언은 enum, re-export 금지(글로벌 컨벤션).

## 3. 비기능 요구사항

- 모바일 세로 화면 최적화, 한 손 조작.
- 순위표 즉시 렌더(데이터 로딩/에러/빈 상태 처리).
- 오프라인/네트워크 오류 시 마지막 데이터 + 경고 표시.
