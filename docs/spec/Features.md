# 기능 요구사항 (화면별)

## 1. 응원국 선택
- 48개 참가국 목록(국기 + 한/영 국가명), 검색 가능.
- 미선택 시 첫 진입에서 강제 선택, 이후 변경 가능.

## 2. 응원국 상태 배너 (항상 상단 고정)
- 조 내 현재 순위, 승점, 남은 경기 수.
- 1·2위면 "자동 진출권", 3위면 "3위 그룹 ○/12위 — 진출 가능 / 경합 / 탈락권".
- 4위면 "직접 진출 불가" + (해당 시) 시뮬레이터 유도.
- **진출 판정 상태**: 남은 모든 경우의 수를 고려해 **진출 확정(clinched) / 탈락 확정(eliminated)
  / 경합 중(in contention)** 을 계산해 표시. (응원국이 3위로 끝난 핵심 상황의 한눈 요약)

## 3. 3위 순위표 (메인)
- 행: 조, 국기, 국가명, 경기수, 승/무/패, 득/실, 골득실, 승점.
- 상위 8 / 하위 4 구분선, 색상 구분, 응원국 강조.
- 라이브 진행 중인 팀은 라이브 뱃지 + 실시간 반영.

## 4. 라이브 경기 영역
- 진행 중 경기 카드(스코어, 진행 시간, 조).
- 폴링 주기로 갱신([DataSource.md](DataSource.md) 참고), 갱신 시각 표시.

## 5. 시뮬레이터
- **핵심 시나리오**: 응원국이 3위로 끝난 뒤, 진출 여부는 **다른 조 3위팀들의 잔여 경기**가 결정.
- **관련 경기 자동 추림**: 모든 조별 잔여 경기 중 **응원국의 8위/9위 경계를 실제로 흔들 수 있는
  경기**를 자동 식별해 우선 노출(나머지는 접어둠). 결과와 무관한 경기로 사용자를 괴롭히지 않음.
- 각 경기에 승/무/패(또는 스코어) 가정 입력 → 입력 즉시 3위 순위표 재계산 →
  "이 결과면 진출 / 탈락" 판정과 바뀐 순위·경계선 표시.
- (응원국 미완료 시) 응원국 자기 경기도 변수로 입력 가능(1·2위 자동진출 vs 3위 갈림).
- "최선/최악 시나리오" 단축: 응원국에 가장 유리/불리한 결과 조합을 자동 적용해 보여주기.
- "초기화"로 실제 데이터 복귀.

> 시뮬레이터 계산 로직 상세는 [Simulator.md](Simulator.md) 참고.
