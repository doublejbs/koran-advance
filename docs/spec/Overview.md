# 개요 / 목표 / 사용자 시나리오

> 2026 FIFA 월드컵 조별리그에서, 사용자가 선택한 응원국이 32강(라운드 오브 32)에
> 진출할 수 있는지를 **3위 팀 순위표** 기준으로 실시간 추적하는 모바일 웹.

## 1. 목표 / 한 줄 정의

- 48개국·12개 조 체제에서 **각 조 3위 12팀 중 상위 8팀**이 추가 진출한다.
- 핵심 질문: **"내가 응원하는 나라가 3위로 끝났을 때, 그 8팀 안에 드는가?"**
- 라이브 경기 스코어를 반영해 3위 순위가 실시간으로 어떻게 변하는지 보여준다.
- "what-if" 시뮬레이터로 남은 경기 결과 가정 시 진출 가능성을 미리 계산한다.

## 2. 사용자 시나리오

1. 앱 진입 → 응원국 선택(검색/국기 목록). 선택값은 로컬 저장.
2. 상단 **응원국 상태 배너**: "현재 조 ○위 / (3위라면) 3위 그룹 내 ○위 / 진출 가능·불가" 요약.
3. **3위 순위표** 탭: 12팀 정렬, 상위 8팀 초록·9~12위 빨강, 응원국 행 하이라이트.
4. 진행 중 경기는 라이브 스코어가 순위표에 즉시 반영(골 변동 → 골득실 재계산).
5. **시뮬레이터** 탭: 응원국이 3위로 끝난 뒤, **다른 조 잔여 경기** 결과를 가정 입력 →
   3위 순위 컷이 어떻게 바뀌어 응원국 진출/탈락이 갈리는지 재계산.
6. 우측 상단 언어 토글(KO/EN).
