# 핵심 도메인 규칙 (2026 월드컵)

- 48개국, 12개 조(A~L), 조별 4팀, 각 팀 3경기.
- 각 조 **1·2위 = 24팀 자동 진출**.
- 각 조 **3위 12팀 중 성적 상위 8팀 추가 진출** → 합계 32강.

## 1. 조 내 순위 결정 (누가 3위인가)

> ⚠️ **2026 월드컵부터 승자승(맞대결)이 전체 골득실보다 우선**으로 변경됨
> (2022까지는 전체 골득실 우선). UEFA 유로 방식과 동일해짐.

1. 승점
2. 승자승 — 동률팀 간 맞대결 승점
3. 승자승 — 맞대결 골득실
4. 승자승 — 맞대결 다득점
5. 전체 골득실차
6. 전체 다득점
7. 팀 행동점수(경고/퇴장 등 페어플레이)
8. FIFA 랭킹 (예전 "추첨"에서 변경)

> 승자승(2~4)은 동률팀 간 미니 리그를 별도 계산해야 함. MVP는 1·5·6(승점→전체 골득실
> →전체 다득점) 우선 구현하고, **승점 동률이 발생할 때만** 승자승 미니테이블을 적용.
> 7~8은 후순위 보완.

## 2. 3위 팀 간 순위 결정 (12팀 줄세우기 → 상위 8팀 진출)

> 3위 팀 비교는 조가 달라 맞대결이 없으므로 **전체 성적**으로만 비교.

1. 승점
2. 골득실차
3. 다득점
4. 팀 행동점수(페어플레이)
5. FIFA 랭킹

12팀 모두 3경기를 치르므로 직접 비교 가능. **상위 8팀 = 진출 / 9~12위 = 탈락.**
